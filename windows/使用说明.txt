MiniMax H3 工作台（Windows 版，64 位）  版本 v1.4（2026-11-15 打包）

怎么用
  1. 把整个文件夹放到一个你有写权限的地方（桌面、文档、移动硬盘都行），不用安装。
  2. 双击「启动.bat」。会开一个黑色的窗口（后台），浏览器自动打开 http://127.0.0.1:8790/ 。
     关掉那个黑色窗口，工作台就停了。
     如果弹出「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。防火墙问是否允许，选允许（只在本机用）。
  3. 第一次用：
     - 点左下角「没有 API Key」，粘贴你的 RunningHub API Key（保存前会验证，加密保存在本机）。
     - 点左边「工作流」，贴上 RunningHub 工作流的 ID，点「添加并核对」。
     - 左边「新建项目」，然后就可以放素材、写提示词、点生成了。

数据在哪
  data 文件夹：项目、工作流库、素材缓存、出的片（data/出片）。
  换电脑、换新版本时，把旧的 data 文件夹整个拷到新包里覆盖即可，项目和记录都还在。
  API Key：Mac 存在系统钥匙串，不在 data 里；Windows 存在 data/_缓存/api_key.bin，是加密的，只有这台电脑的这个账户能解开。
  所以换电脑时不管哪个版本都要重新填一次 Key（Windows 拷过去的那个文件解不开，不会泄露）。

让 AI 助手用工作台（MCP）
  点工作台左下角的「MCP」：
  - Claude 桌面版：点「一键写入 Claude 桌面版」（会先备份原来的配置文件），然后完全退出 Claude（菜单里的「退出」）再打开。
  - ChatGPT 桌面版（Codex）：设置 → MCP servers → 添加 → 类型选 STDIO，命令和参数照「MCP」里写的填；
    或者点「复制 config.toml 写法」，贴进 ~/.codex/config.toml 。
  - 只认网址的软件：在「MCP」里打开「网址接口」，复制网址和口令。只在本机能用。
  - 工作台要开着，助手才连得上。整个文件夹挪了位置或换了新版本，回到「MCP」里重新写一次。
  - 默认助手不能自己扣费提交：只能把设置放进生成框、由你点「生成」，或者先检查拿到确认码再交。
    「自动提交」打开后，助手可以直接提交到 RunningHub 扣费；打开时会弹系统确认框，要你亲手点。

说明
  - 只在本机运行，网页只有这台电脑能打开；生成在 RunningHub 上跑，按 RunningHub 的规则扣费。
  - 每次提交前都有确认框。
  - 包里带的 Python、FFmpeg 的来源和许可见 runtime/LICENSES.txt。
  - FFmpeg 按 GPL v3 授权：三年内可以免费索取它这次构建的完整源码，索取方式见 runtime/LICENSES.txt 里的「源码书面承诺」。
